If you already have OxRefine, the desktop app offers this update when it starts. **[Documentation](https://ilyaux.github.io/OxRefine/)**: install, coming from OpenRefine, guides and the GREL reference.

The installers aren't code-signed yet. On Windows, SmartScreen may warn you: choose *More info* → *Run anyway*. On macOS, right-click the app, choose *Open*, then confirm.

## New

- **`ox` for any Linux.** `ox-…-x86_64-unknown-linux-musl` is one static program that needs no system libraries. It runs on Alpine, and on systems whose glibc is older than the regular build needs, such as RHEL, Alma or Rocky Linux 8. `ox serve` gives you the whole app in a browser there, and `ox apply` replays recipes. Every release now runs it on Alpine and Alma Linux 8, Python expressions included, before it is published. Requested in [#1](https://github.com/ilyaux/OxRefine/issues/1).

The desktop app on Linux still needs a distribution at least as recent as Ubuntu 22.04. Everything in [0.7.0](https://github.com/ilyaux/OxRefine/releases/tag/v0.7.0) (Python and Clojure expressions, extensions, Google Sheets) is here too.
