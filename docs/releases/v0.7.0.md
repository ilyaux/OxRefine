## New

- **Python and Clojure expressions.** The expression editor has a GREL / Python / Clojure switch, like OpenRefine's, and steps keep OpenRefine's `jython:` and `clojure:` prefixes, so recipes move both ways. Python runs in a built-in Python with the Python 2 habits Jython expressions rely on (integer division, `print x`, `except E, e:`, `unicode`, `has_key`); Clojure runs in OxRefine's own interpreter. 334 of 337 reference expressions give OpenRefine 3.10.1's exact result; the three differences are listed. [How it works](https://ilyaux.github.io/OxRefine/transforming.html#python-and-clojure).
- **Extensions.** Drop a folder with a `main.py` into the `extensions` folder to add GREL functions, importers, exporters and operations, no rebuild needed. Operations are undoable steps that go into recipes. **Preferences → Extensions** shows what is installed. [Write one](https://ilyaux.github.io/OxRefine/extensions.html), or start from the [text-tools example](https://github.com/ilyaux/OxRefine/tree/main/docs/extensions/text-tools).
- **Google Sheets.** **New project → Google Sheets** imports a spreadsheet by its link, every sheet through the Excel preview; a sheet shared with anyone who has the link needs no sign-in. Signed in, you can pick from your Drive, import private sheets, send rows to a new Google Sheet and upload the project to Drive. Signing in needs an OAuth client you register with Google ([how](https://ilyaux.github.io/OxRefine/importing.html#google-sheets-and-drive)), because Google issues those per app.

## Improved

- A Google Sheets link pasted into **From a web address** downloads the spreadsheet instead of its web page.
- Questions asked one after another (an extension operation's parameters) each start from their own default.

## Not yet

RDF import, the scatterplot facet, Wikibase schemas and uploads, and translations. The full plan is in [ROADMAP.md](https://github.com/ilyaux/OxRefine/blob/main/ROADMAP.md).

The download is larger than 0.6.0 because of the built-in Python and its standard library. Speed is unchanged against 0.6.0 (CI's benchmark at 250k and 1M rows), and peak memory is about 4 MB higher: 54 MB against 50 MB at 250k rows, 149 against 145 MB at 1M.
