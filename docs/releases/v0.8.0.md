# OxRefine 0.8.0

OpenRefine's extensions: Wikibase and Wikidata, RDF import and a way to run Java extension steps. Also custom clustering functions, the scatterplot facet, MCP without a server, and `ox serve` behind any reverse proxy.

## New

- **Wikibase and Wikidata.** [Edit Wikibase schema…](https://ilyaux.github.io/OxRefine/wikibase.html) in the command palette builds items and media info from your columns: terms, statements, qualifiers, references and their modes, with a live preview of the edits and their issues. The schema is kept with the history and in OpenRefine archives and recipes. Export it as QuickStatements, check rows with `wikibaseIssues()` (property constraints included), and upload the edits to Wikidata, Wikimedia Commons (files too) or another Wikibase with a bot password or OAuth. An upload step never edits twice on undo or replay. Requests, edits and issues match OpenRefine 3.10.1's, recorded against a mock MediaWiki API.
- **RDF import:** Turtle, N3, N-Triples, RDF/XML and JSON-LD, into the same table as OpenRefine's RDF importer: a record per subject, a column per predicate.
- **OpenRefine's Java extensions.** OxRefine can't load Java modules, but with an OpenRefine folder in Preferences → Extensions, *Run steps in OpenRefine…* runs a recipe's steps in that OpenRefine, with its extensions, and opens the result as a new project with its history.
- **Custom clustering functions.** *Add keying function…* and *Add distance function…* in the cluster dialog, in GREL, Python or Clojure, kept in the preferences under OpenRefine's names.
- **Scatterplot facet.** *Scatterplot facet…* in a column's menu shows the numeric columns' pairs; drag a rectangle on a pair's plot to keep the rows inside. It keeps the rows OpenRefine keeps; see [the differences](https://ilyaux.github.io/OxRefine/differences.html#scatterplot-facets) for why the plots are linear only.
- **MCP without `ox serve`.** `ox mcp` attaches to the server of its data folder or hosts the folder itself, and `ox serve` answers MCP over HTTP at `/mcp`. New tools preview imports, rename and delete projects, list GREL functions and extensions and guess reconciliation types; projects can be created from a web address or pasted text.

## Fixed

- **`ox serve` behind a reverse proxy, once more.** With a slash on one side only, as in Apache's `ProxyPass /refine http://127.0.0.1:3333/`, the proxy sends `//assets/…`. OxRefine answered those with the page instead of the scripts, and the browser showed a blank page. Repeated slashes now count as one, and a missing file is a 404, never the page. CI checks both kinds of proxy. Reported in [#3](https://github.com/ilyaux/OxRefine/issues/3).
- **`levenshteinDistance()` ignores case,** as OpenRefine's does: `levenshteinDistance("New York", "new york")` is 0.
