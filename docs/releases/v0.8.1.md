## Fixed

- **`ox serve --token`: the app needs the token too.** Opening the server address without `?token=…` showed the whole app, only without projects. Now that address gets only a short note asking for the link, and every request without the token is refused. The scripts and styles, the same published build for everyone, stay open; they hold no data. CI checks a token-protected server behind a reverse proxy. Reported in [#5](https://github.com/ilyaux/OxRefine/issues/5).

Everything new in 0.8.0 (Wikibase and Wikidata, RDF import, OpenRefine extension steps, custom clustering functions, the scatterplot facet, MCP without a server) is in [its release notes](https://github.com/ilyaux/OxRefine/releases/tag/v0.8.0).
