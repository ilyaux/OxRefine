## Fixed

- **`ox serve` behind a reverse proxy.** The browser app asked for its scripts and its API at the site's root (`/assets/…`, `/api/…`), so under a path such as `https://intranet.example.com/refine/` the page stayed blank. Every address is relative now, `/refine` moves itself to `/refine/`, and the documentation has [Apache and nginx examples](https://ilyaux.github.io/OxRefine/command-line.html#behind-a-reverse-proxy), with the timeouts and Host header to watch. CI now runs `ox serve` behind a proxy at a sub-path on every change. Reported in [#3](https://github.com/ilyaux/OxRefine/issues/3).
- **`ox --help` and `ox --version`** (also `-h`, `help`, `-V`, `version`) print to standard output and exit 0, as service scripts and package tools expect. Asked for in [#4](https://github.com/ilyaux/OxRefine/issues/4).
