## New

- **[Running OxRefine on a server](https://ilyaux.github.io/OxRefine/deploying.html),** a guide: who gets in, the configuration for nginx, Apache httpd, Caddy, Traefik and Pound at a site root or a path such as `/ox/`, a systemd service, Docker, health checks, logs, and what each error means. CI runs each of those proxies on every change, with and without a token, uploads, downloads and MCP included.
- **`--allow-host NAME`.** Caddy, Traefik and Pound pass on the visitor's host name, which OxRefine without a token used to refuse with nothing but a 403: the page loaded and nothing worked. Name the address people use with `--allow-host` (or use a token) and they get in.
- **Refusals say what to do.** A refused browser gets a note instead of the app, an API client the same text, and `ox serve` prints it once with the flag to add.
- **`OXREFINE_TOKEN`** sets the token from the environment, out of the process list, for system services and Docker (`-e OXREFINE_TOKEN=…`).
- **`/healthz`** answers `ok` without a token, for load balancers and container health checks, and `HEAD` works everywhere. **`--log`** prints each request, never its token.

## Fixed

- **The Docker image builds again.** It had been missing a file and a library since 0.8.0; CI now builds it and uses it.
- **The token stays out of proxy logs' referrer field and away from other sites** (`Referrer-Policy: no-referrer`).
- Without a token, `localhost` without a port and `[::1]` are answered too, not only `127.0.0.1:PORT` and `localhost:PORT`.
